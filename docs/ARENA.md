# 리온의 숲속대결 — 설계

세 번째 게임. 『브롤스타즈』 **쇼다운(솔로)** 모드의 *규칙 구조*를 참고한 탑뷰 서바이벌.
원작의 이름·캐릭터·그림·맵은 쓰지 않는다. 규칙만 빌리고 나머지는 이 레포 것
(리온 · 대모험 적들 · 코드로 그린 숲)으로 채운다.

## 2. 규칙 (숫자는 `src/arena/tuning.ts`)

- 맵: 48×32 타일, 타일 12px (576×384). 화면(416×192)보다 크므로 카메라가 따라간다.
  4분면 대칭으로 만든다 — 손으로 1/4만 그리고 나머지는 거울로 복사해서 공평하다.
- 체력 100, 별 하나당 최대 체력 +10 · 공격력 +10%.
- 탄창 3칸, 칸당 재장전 1초 남짓. 무기마다 사거리·탄수·피해가 다르다.
- 수풀 속 파이터는 2.5타일 안에 들어온 상대에게만 보인다. 쏘면 1초간 드러난다.
- 독안개: 시작 20초 뒤부터 70초에 걸쳐 바깥에서 조여 와 가운데 15%만 남는다. 초당 20 피해.
- 리온이 쓰러지면 그 자리에서 판이 끝난다(순위 = 살아남은 수 + 1).
  **1등을 해야 "클리어"** — 다음 판이 열린다.
- 연습: 봇 피해 60%, 반응이 느리다. 도전: 원래대로, 기록을 남긴다.

## 3. 조작

| | 터치 | 키보드 |
|---|---|---|
| 이동 | 화면 왼쪽 아무 데나 대고 끌기 (떠 있는 조이스틱) | WASD · 방향키 |
| 공격 | 오른쪽 아래 버튼. **누르고 있으면** 가장 가까운 적을 자동 조준해 계속 쏜다 | Space · J |
| 필살기 | 공격 버튼 왼쪽 위의 작은 버튼 (게이지 찼을 때) | K · X |

적이 없으면 가까운 상자를, 그것도 없으면 바라보는 방향을 쏜다.

## 4. 구조

`docs/ADD-GAME.md` 절차를 그대로 따른다. 기존 두 게임 코드는 건드리지 않는다.

순수 계층 `src/arena/` (DOM 금지, eslint PURE 목록):

| 파일 | 책임 |
|---|---|
| `types.ts` | 상태 타입 |
| `tuning.ts` | 상수 · 무기표 |
| `grid.ts` | 맵 파싱 · 타일 충돌 · 시야(수풀) · BFS 길찾기 |
| `maps.ts` | 6판 (4분면 아스키 + 대칭 복사) |
| `schema.ts` | 맵 검증 — 크기 · 스폰 수 · 스폰끼리 이어지는가 |
| `combat.ts` | 이동 · 사격 · 탄 · 피해 · 별 · 회복 · 독안개 |
| `ai.ts` | 봇 판단 (독 피하기 → 도망 → 공격 → 상자 → 배회) |
| `update.ts` | 한 프레임 |
| `scenes.ts` | 씬 전이 · 순위 · 기록 |

난수는 `src/sky/rng.ts` 의 결정적 LCG 를 같이 쓴다 — 같은 seed 면 같은 판.

껍데기: `src/render/arena.ts`(그리기), `src/ui/arenaUi.ts`(타이틀·판 고르기·결과·조작 버튼),
`src/arenaApp.ts`(접착부). 허브 등록 id 는 `arena`.

그림: 리온은 아틀라스 `face`, 봇은 대모험 적 프레임(브로콜리·악어·수프·가시·날개·던지기)을
그대로 쓴다. 타일·수풀·안개는 코드로 그린다.

## 5. 구현 순서 (계획)

1. 순수 계층 — tuning/types → grid → maps+schema → combat → ai → update → scenes
2. 테스트 — 충돌·탄·수풀 시야·독안개·별·회복·필살기·씬, 6판 검증,
   **봇끼리 끝까지 돌려 판이 반드시 끝나는지**, AI 리온이 1판을 이길 수 있는지
3. 껍데기 — 렌더러 · UI · 앱 · main.ts 라우팅 · 허브 카드
4. 검증 — `npm test && npm run lint && npm run build`, 미리보기 PNG 로 눈 확인

## 6. 밸런스는 측정으로 정했다

`tools/arena_balance.mts` 가 리온에게 봇 두뇌(`AUTOPILOT`, 조준 오차 0 — 진짜 리온은
자동 조준이라 오차가 없다)를 붙여 판마다 30 seed 를 돌린다.

```
npx vite-node tools/arena_balance.mts 30
```

처음엔 봇 피해를 연습에서만 0.6배로 줄였는데, 도전 1판 승률이 10% 였다.
아이에게는 너무 어렵다. 봇이 **리온에게** 주는 피해만 모드별로 줄였다
(`BOT_DMG_TO_PLAYER` 연습 0.45 · 도전 0.8, 봇끼리는 원래대로).

| 모드 | 1판 | 2판 | 3판 | 4판 | 5판 | 6판 |
|---|---|---|---|---|---|---|
| 연습 승률 | 50% | 47% | 43% | 47% | 53% | 47% |
| 도전 승률 | 17% | 17% | 20% | 27% | 33% | 20% |

판 길이는 평균 30~45초, 최장 80초 안쪽. 독안개 덕에 끝나지 않는 판은 0.
봇 리온은 수풀에 숨지도, 일부러 마지막까지 버티지도 않는다 — 사람이 하면 이보다 쉽다.
뒤 판으로 갈수록 친구 수가 늘어 1등 확률 자체는 낮아지므로, 봇 조준만 조금씩 좋아지게 했다.

## 8. 일부러 안 한 것

- 수동 조준(오른쪽 조이스틱) — 자동 조준만. 버튼을 누르고 있으면 계속 쏜다
- 맵 밖 적 표시·미니맵 — 맵이 화면의 1.4×2 배라 카메라만으로 충분했다
- 판 전용 BGM — 하늘전투 곡을 같이 쓴다
