## 실행 중 잡은 버그 (전부 구현 쪽)

1. **땅에 서 있는 몸이 매 프레임 번갈아 공중 판정** — `vy === 0`에서 `moveY`의 두 분기를 모두 건너뜀. 코요테 타임이 계속 리셋되고 착지 이벤트가 반복 발동. 발밑 탐침으로 수정
2. **부동소수 좌표에서 충돌 최대 1px 미검출** — 정수 관례 `-1`이 `y+h=48.83`의 0.83px 침범을 놓침. `-EPS`로 교체
3. **축구공이 스폰 순간 바닥에 박힘** — 세로 중심 미정렬
4. **복숭아가 벽에서 반전 대신 정지** — `moveX`가 `vx`를 0으로 만든 뒤 `Math.sign(0)`을 읽음
5. **검증 규칙 6의 구멍** — 천장까지 꽉 찬 열이 통과
6. **골든 스냅샷이 물리 변경을 놓칠 수 있음** — 부활이 궤적 차이를 씻어버림. `traceHash` 추가

계획 문서 상단에 기록. 그중 두 개는 스펙이 사실과 달랐던 것:
